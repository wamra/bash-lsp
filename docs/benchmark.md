## Limits

- The corpus (`bench/testdata/corpus2`) and every expectation were written by an agent, from the bash manual and the LSP 3.17 typings, before any server output was seen. No human has audited them.
- One machine, macOS only. Linux and Windows are not measured.
- bash-lsp only. The competing servers are not run on this suite yet (Task 14), and the `bash -n` and `bash-trace` oracles are cross-checked only in Task 14.
- The server runs with shellcheck disabled (`bench/config-shellcheck-off.toml`), so diagnostics are the native ones.
- Each case runs on a fresh server over a fresh copy of the corpus; the file is opened and the harness waits 2 s before asking. Latency-sensitive failures were re-run with 6 s and stayed failing.
- Case expectations were frozen before the first result; none was edited afterwards. Gating cases are the contract, design cases (soft design assumptions) are reported separately.
